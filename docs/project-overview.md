# Gambaran proyek

iBouTix adalah prototype akademik untuk penemuan dan simulasi pemesanan tiket konser, festival musik, dan hiburan. Tahap awal ini menyediakan halaman statis, data contoh, serta API Go kecil sebagai fondasi pembagian kerja tim.

Pembagian awal yang bisa dikembangkan:

- Frontend: HTML, CSS, dan JavaScript tanpa framework.
- Backend: Go standard library, `net/http`, model dan service.
- Data: contoh JSON sebagai sumber data dan CSV untuk pertukaran tabular.
- Processor: direktori C dan COBOL disiapkan, implementasinya belum dimulai.

## Arah visual prototype

Tampilan memakai warna tinta, kertas hangat, merah bata, dan amber agar terasa seperti materi acara musik cetak, bukan panel SaaS. Manrope dipakai untuk judul yang tegas dan DM Sans untuk teks antarmuka yang mudah dibaca. Dials: ENERGY 2 / RHYTHM 2 / MOTION 1. Ilustrasi poster dibuat dengan CSS supaya tidak memakai foto acara yang seolah nyata.
